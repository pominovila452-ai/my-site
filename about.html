О проекте

Я сделал этот сайт, чтобы применить на практике то, что изучаю на занятиях по веб-программированию.

В проекте я попробовал несколько базовых инструментов:

  • HTML5 — чтобы задать структуру и содержание;
  • CSS — чтобы настроить цвета, размеры и расположение блоков;
  • Bootstrap — чтобы использовать готовую сетку и элементы интерфейса;
  • GitHub Pages — чтобы разместить готовые страницы в интернете.
